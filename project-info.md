# Роли пользователей

При регистрации пользователю назначается роль `regular`. Администраторов может быть несколько; роль `admin` назначается и изменяется **только вручную через БД**. API для назначения или смены роли администратора нет.

# Профиль пользователя

`GET /users/me` возвращает профиль по активной сессии. `GET /users/:uuid` публично возвращает полный профиль другого пользователя, включая email, телефон и дату рождения, если они заполнены. `GET /users/all` доступен только администратору. Пароль и его хеш не возвращаются.
